# Awesome macOS Apps [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

A curated list of Mac apps that are worth installing and still maintained.

Each app gets one factual line, sorted alphabetically within its section. To stay listed, an app has to keep getting updates (the rules are in [CONTRIBUTING.md](CONTRIBUTING.md)), and every link is checked weekly.

Last reviewed: 2026-10-25 · [What changed](CHANGELOG.md)

🆓 Free&nbsp;&nbsp;·&nbsp;&nbsp;🔹 Free plan with a paid upgrade&nbsp;&nbsp;·&nbsp;&nbsp;No mark: paid, usually with a free trial&nbsp;&nbsp;·&nbsp;&nbsp;🔓 Open source (links to the code)

> **Disclosure:** this list is maintained by [Mike Le](https://github.com/mikeqle), who makes [Super Shortcuts](https://supershortcuts.com/) (listed under Keyboard and Shortcuts). It follows the same rules as every other entry. Corrections and additions are welcome: see [CONTRIBUTING.md](CONTRIBUTING.md).

## Keyboard and Shortcuts

- [BetterTouchTool](https://folivora.ai/) - Custom gestures, keyboard shortcuts and actions for trackpads, mice and keyboards.
- [Hammerspoon](https://www.hammerspoon.org/) - Automate macOS with Lua scripts that bind keys, windows and system events. 🆓 [🔓](https://github.com/Hammerspoon/hammerspoon)
- [Homerow](https://www.homerow.app/) - Click, scroll and select anything on screen from the keyboard.
- [Hyperkey](https://hyperkey.app/) - Turn Caps Lock or another key into a Hyper key. 🆓
- [Karabiner-Elements](https://karabiner-elements.pqrs.org/) - Remap any key and build complex modifications with rules. 🆓 [🔓](https://github.com/pqrs-org/Karabiner-Elements)
- [Keyboard Maestro](https://www.keyboardmaestro.com/) - Macros triggered by hotkeys, typed strings, menus, devices and more.
- [KeyCastr](https://github.com/keycastr/keycastr) - Show your keystrokes on screen for demos and recordings. 🆓 [🔓](https://github.com/keycastr/keycastr)
- [Super Shortcuts](https://supershortcuts.com/) - Hold a Super key like Caps Lock and each key runs a shortcut for the app or website you're in. 🔹

## Launchers

- [Alfred](https://www.alfredapp.com/) - Launcher with search, clipboard history, snippets and workflows. 🔹
- [LaunchBar](https://www.obdev.at/products/launchbar/) - Keyboard launcher for apps, files, contacts and actions.
- [Raycast](https://www.raycast.com/) - Command palette with extensions, snippets, window commands and AI. 🔹

## Window Management

- [AeroSpace](https://github.com/nikitabobko/AeroSpace) - Tiling window manager in the style of i3, configured in a text file. 🆓 [🔓](https://github.com/nikitabobko/AeroSpace)
- [AltTab](https://alt-tab-macos.netlify.app/) - Windows-style window switcher with previews of every window. 🆓 [🔓](https://github.com/lwouis/alt-tab-macos)
- [Amethyst](https://ianyh.com/amethyst/) - Automatic tiling window manager with layouts you cycle through. 🆓 [🔓](https://github.com/ianyh/Amethyst)
- [Command Reopen](https://commandreopen.com/) - Makes Cmd+Tab restore minimized and closed windows with zero permissions. [🔓](https://github.com/Feng6611/mac-command-reopen)
- [Loop](https://github.com/MrKai77/Loop) - Resize windows with a radial menu and keyboard shortcuts. 🆓 [🔓](https://github.com/MrKai77/Loop)
- [Magnet](https://magnet.crowdcafe.com/) - Snap windows to halves, thirds and corners by dragging or shortcut.
- [Moom](https://manytricks.com/moom/) - Move and zoom windows to saved layouts and grid positions.
- [Rectangle](https://rectangleapp.com/) - Move and resize windows with keyboard shortcuts and snap areas. 🆓 [🔓](https://github.com/rxhanson/Rectangle)

## Menu Bar

- [Bartender](https://www.macbartender.com/) - Hide, rearrange and show menu bar items.
- [Ice](https://icemenubar.app/) - Hide and show menu bar items, with a separate bar for the hidden ones. 🆓 [🔓](https://github.com/jordanbaird/Ice)
- [iStat Menus](https://bjango.com/mac/istatmenus/) - Detailed CPU, memory, disk, network and sensor readings in the menu bar.
- [Itsycal](https://www.mowglii.com/itsycal/) - Small menu bar calendar with your events. 🆓 [🔓](https://github.com/sfsam/Itsycal)
- [Stats](https://github.com/exelban/stats) - System monitor for the menu bar: CPU, GPU, memory, disk, network, battery. 🆓 [🔓](https://github.com/exelban/stats)
- [Vorssaint](https://vorssaint.com/) - Menu bar toolkit with per-app volume, a system monitor, window snapping, clipboard history and more; install only the parts you use (Apple Silicon). 🆓 [🔓](https://github.com/vorssaint/vorssaint-utils)

## Clipboard and Text Expansion

- [Espanso](https://espanso.org/) - Text expander configured in YAML files, with forms and scripts. 🆓 [🔓](https://github.com/espanso/espanso)
- [Maccy](https://maccy.app/) - Lightweight, keyboard-first clipboard history. 🆓 [🔓](https://github.com/p0deje/Maccy)
- [Paste](https://pasteapp.io/) - Clipboard history and pinboards, synced across Apple devices.
- [PopClip](https://www.popclip.app/) - Actions that appear when you select text: copy, search, transform and extensions.
- [TextExpander](https://textexpander.com/) - Snippets that expand as you type, shared across a team.
- [Typinator](https://www.ergonis.com/products/typinator/) - Text expansion with abbreviations, rules and autocorrect sets.

## Notes and Writing

- [Bear](https://bear.app/) - Markdown notes with tags, linking and a focused editor. 🔹
- [Craft](https://www.craft.do/) - Documents and notes made of blocks, with sharing and pages. 🔹
- [Drafts](https://getdrafts.com/) - Capture text quickly, then send it anywhere with actions. 🔹
- [iA Writer](https://ia.net/writer) - Markdown writing app built around a distraction-free editor.
- [Joplin](https://joplinapp.org/) - Markdown notes and to-dos with end-to-end encrypted sync. 🆓 [🔓](https://github.com/laurent22/joplin)
- [Logseq](https://logseq.com/) - Outliner for linked notes and journals stored as local files. 🆓 [🔓](https://github.com/logseq/logseq)
- [MarkEdit](https://github.com/MarkEdit-app/MarkEdit) - Lightweight native Markdown editor. 🆓 [🔓](https://github.com/MarkEdit-app/MarkEdit)
- [Obsidian](https://obsidian.md/) - Markdown knowledge base on local files, with links, graph and plugins. 🔹
- [Typora](https://typora.io/) - Markdown editor that renders as you type.
- [Ulysses](https://ulysses.app/) - Writing app for long texts, with a library and publishing.

## Tasks and Calendar

- [Fantastical](https://flexibits.com/fantastical) - Calendar and tasks with natural-language event entry. 🔹
- [OmniFocus](https://www.omnigroup.com/omnifocus) - Task manager built around projects, contexts and reviews.
- [Things](https://culturedcode.com/things/) - Personal task manager with areas, projects and a Today list.
- [Todoist](https://www.todoist.com/) - Cross-platform to-do list with projects, labels and natural-language dates. 🔹

## Screenshots and Screen Recording

- [CleanShot X](https://cleanshot.com/) - Screenshots and recordings with annotation, scrolling capture and cloud links.
- [OBS Studio](https://obsproject.com/) - Video recording and live streaming with scenes and sources. 🆓 [🔓](https://github.com/obsproject/obs-studio)
- [Screen Studio](https://screen.studio/) - Screen recorder that adds automatic zoom and smooth cursor movement.
- [Shottr](https://shottr.cc/) - Fast screenshots with annotation, OCR, scrolling capture and measuring. 🔹

## Developer Tools

- [Dash](https://kapeli.com/dash) - Offline API documentation browser and snippet manager. 🔹
- [Fork](https://git-fork.com/) - Git client with a fast commit graph, interactive rebase and merge tool.
- [GitHub Desktop](https://desktop.github.com/) - GitHub's Git client for commits, branches and pull requests. 🆓 [🔓](https://github.com/desktop/desktop)
- [Homebrew](https://brew.sh/) - Package manager for command-line tools and apps. 🆓 [🔓](https://github.com/Homebrew/brew)
- [OrbStack](https://orbstack.dev/) - Runs Docker containers and Linux machines. 🔹
- [Proxyman](https://proxyman.com/) - HTTP and HTTPS debugging proxy for apps, browsers and devices. 🔹
- [TablePlus](https://tableplus.com/) - Database client for PostgreSQL, MySQL, SQLite, Redis and more. 🔹
- [Tower](https://www.git-tower.com/) - Git client with drag-and-drop branching and undo.

## Terminals and Code Editors

- [Ghostty](https://ghostty.org/) - Fast, native, GPU-accelerated terminal emulator. 🆓 [🔓](https://github.com/ghostty-org/ghostty)
- [iTerm2](https://iterm2.com/) - Terminal with split panes, search, profiles and shell integration. 🆓 [🔓](https://github.com/gnachman/iTerm2)
- [Nova](https://nova.app/) - Native code editor by Panic, with extensions.
- [Sublime Text](https://www.sublimetext.com/) - Fast text and code editor with multiple cursors and a command palette.
- [Visual Studio Code](https://code.visualstudio.com/) - Code editor with debugging, Git and a large extension library. 🆓 [🔓](https://github.com/microsoft/vscode)
- [Warp](https://www.warp.dev/) - Terminal with blocks, command search and AI assistance. 🔹
- [Zed](https://zed.dev/) - Code editor written in Rust, with real-time collaboration. 🆓 [🔓](https://github.com/zed-industries/zed)

## Files and System Utilities

- [Amphetamine](https://apps.apple.com/app/amphetamine/id937984704) - Keep your Mac awake, with triggers and schedules. 🆓
- [AppCleaner](https://freemacsoft.net/appcleaner/) - Uninstall apps together with their leftover files. 🆓
- [BetterDisplay](https://github.com/waydabber/BetterDisplay) - Control resolution, scaling, brightness and virtual displays. 🔹
- [ForkLift](https://binarynights.com/) - Dual-pane file manager with remote connections and sync.
- [Hazel](https://www.noodlesoft.com/) - Rules that file, rename and clean up folders automatically.
- [Keka](https://www.keka.io/) - Archiver for 7z, zip, rar and other formats. 🆓 [🔓](https://github.com/aonez/Keka)
- [Latest](https://max.codes/latest/) - Shows which installed apps have updates. 🆓 [🔓](https://github.com/mangerlahn/Latest)
- [MonitorControl](https://github.com/MonitorControl/MonitorControl) - Brightness and volume keys for external displays. 🆓 [🔓](https://github.com/MonitorControl/MonitorControl)
- [Mos](https://mos.caldis.me/) - Smooth scrolling and per-device scroll direction for mice. 🆓 [🔓](https://github.com/Caldis/Mos)
- [The Unarchiver](https://theunarchiver.com/) - Opens rar, 7z, tar and many other archive formats. 🆓

## Browsers

- [Brave](https://brave.com/) - Chromium-based browser that blocks ads and trackers by default. 🆓 [🔓](https://github.com/brave/brave-browser)
- [Firefox](https://www.mozilla.org/firefox/) - Mozilla's browser, with containers and extensive extensions. 🆓 [🔓](https://github.com/mozilla-firefox/firefox)
- [Google Chrome](https://www.google.com/chrome/) - Google's browser, synced with your Google account. 🆓
- [Orion](https://kagi.com/orion/) - WebKit browser that runs Chrome and Firefox extensions. 🔹
- [Vivaldi](https://vivaldi.com/) - Chromium-based browser with tab stacks, panels and deep customisation. 🆓

## Audio and Video

- [Audio Hijack](https://rogueamoeba.com/audiohijack/) - Record and process audio from any app or device.
- [HandBrake](https://handbrake.fr/) - Video transcoder with presets for devices and formats. 🆓 [🔓](https://github.com/HandBrake/HandBrake)
- [IINA](https://iina.io/) - Modern video player built on mpv. 🆓 [🔓](https://github.com/iina/iina)
- [SoundSource](https://rogueamoeba.com/soundsource/) - Per-app volume, output devices and audio effects from the menu bar.
- [VLC](https://www.videolan.org/vlc/) - Media player for nearly every video and audio format. 🆓 [🔓](https://github.com/videolan/vlc)

## Design and Images

- [Figma](https://www.figma.com/downloads/) - Collaborative interface design and prototyping. 🔹
- [ImageOptim](https://imageoptim.com/mac) - Shrinks images losslessly and strips metadata. 🆓 [🔓](https://github.com/ImageOptim/ImageOptim)
- [Pixelmator Pro](https://www.pixelmator.com/pro/) - Image editor with layers, vector tools and machine-learning features.
- [Sketch](https://www.sketch.com/) - Native interface design tool with symbols and libraries.

## Security and Passwords

- [1Password](https://1password.com/) - Password manager with passkeys, shared vaults and browser fill.
- [Bitwarden](https://bitwarden.com/) - Password manager with a free plan and self-hosting. 🔹 [🔓](https://github.com/bitwarden/clients)
- [Little Snitch](https://www.obdev.at/products/littlesnitch/) - Shows and controls every app's network connections.
- [LuLu](https://objective-see.org/products/lulu.html) - Firewall that alerts on and blocks unknown outgoing connections. 🆓 [🔓](https://github.com/objective-see/LuLu)

## Reading and RSS

- [NetNewsWire](https://netnewswire.com/) - RSS reader with iCloud and feed-service sync. 🆓 [🔓](https://github.com/Ranchero-Software/NetNewsWire)
- [Reeder](https://reederapp.com/) - Reader for feeds, social timelines and saved links.

## Local AI

- [LM Studio](https://lmstudio.ai/) - Download and run open language models on your Mac, with a chat and a local API. 🆓
- [MacWhisper](https://goodsnooze.gumroad.com/l/macwhisper) - Transcribe audio and video on-device with Whisper models. 🔹
- [Ollama](https://ollama.com/) - Run open language models locally from the command line or an API. 🆓 [🔓](https://github.com/ollama/ollama)
